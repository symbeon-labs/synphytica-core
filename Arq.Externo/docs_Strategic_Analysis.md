## PARTE 1: VISÃO GERAL
SynPhytica é uma plataforma de IA para design racional de fitofármacos. Diferente de sistemas de recomendação simples, SynPhytica projeta formulações molécula-por-molécula.

### Inovações Chave
1. **Modelagem de Sinergia via Transformers**: Captura o "efeito entourage" computacionalmente.
2. **Otimização Híbrida**: GA + PSO para navegar espaços químicos complexos.
3. **Agnóstico à Planta**: Validado em Cannabis, pronto para TCM e Ayurveda.
