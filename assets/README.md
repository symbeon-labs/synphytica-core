## 📝 Diretrizes de Uso

### Branding
- Manter consistência de cores
- Usar logo em fundos claros ou escuros
- Não distorcer proporções

### Documentação
- Incluir legendas descritivas
- Manter alta resolução para impressão
- Citar fonte quando usar em publicações

### Apresentações
- Usar imagens em slides de título e conceito
- Diagrama de arquitetura para explicações técnicas
- Logo no rodapé de slides
